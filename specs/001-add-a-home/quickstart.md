# Quickstart: Home Page, Navigation, and Auth UI

## Setup
1. Install dependencies in `frontend/` and `backend/`
2. Configure SQLite in `backend/`
3. Start backend Express server
4. Start frontend React/Vite app

## Usage
- Register a new user via Registration page
- Log in via Login page
- Navigate using sidebar and navbar icons

## Test Scenarios
- Register with valid/invalid data
- Log in with correct/incorrect credentials
- Attempt duplicate registration
- Navigate between pages using sidebar/navbar
- Validate error handling for network/server issues
